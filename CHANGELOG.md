# История версий Oxide

## 1.0.3 — 2026-11-19

- В окне «О программе» — уведомление, что Oxide не связан с Microsoft.
- Добавлен файл THIRD_PARTY_LICENSES.md с лицензиями всех сторонних библиотек.
- Встроенные шрифты egui убраны: Oxide использует только шрифты Windows (меньше exe).

## 1.0.2 — 2026-11-19

- Рамка выделения мышью на «Главной» и в «Этот компьютер», выбор нескольких плиток (Ctrl+щелчок).
- Щелчок по пустому месту снимает выделение (и ниже последнего файла тоже).
- Рамка выделения полупрозрачная и системного синего цвета, файлы под ней видны.
- В таблице рамка тянется с пустой части строки (дата, тип, размер), как в Проводнике.

## 1.0.1 — 2026-11-19

- Из exe убраны пути компьютера сборки (имя пользователя Windows, папка проекта): файл можно передавать другим.

## 1.0.0 — 2026-11-19

Первый выпуск.

- Интерфейс Проводника Windows 11: вкладки в заголовке, строка адреса с «хлебными крошками»,
  поиск, командная панель («Создать», «Сортировать», «Просмотреть», «Сведения»), область навигации,
  строка состояния, Snap Layouts на кнопке «Развернуть».
- Виды: огромные, крупные, обычные, мелкие значки, список, таблица, плитка, содержимое; компактный вид;
  эскизы изображений и видео; флажки элементов.
- Контекстное меню Windows 11 и полное системное меню («Показать дополнительные параметры», Shift+F10).
- Копирование, перемещение, удаление в Корзину и переименование через движок Windows
  (родные окна прогресса и конфликтов), отмена (Ctrl+Z), буфер обмена, совместимый с Проводником,
  перетаскивание в другие программы и из них.
- Мгновенный поиск по индексу всех дисков (MFT с правами администратора, иначе параллельный обход),
  живое обновление индекса.
- Главная (Быстрый доступ, Последние), Этот компьютер (диски с заполнением), Галерея, Сеть, Корзина,
  ZIP-архивы как папки, «Сжать в ZIP», «Извлечь все».
- Область сведений и область просмотра.
- Семь интерфейсов: как в Windows, Windows 11 светлая и тёмная, Oxide, Графит, Северная ночь, Бумага.
- Настройки при первом запуске берутся из параметров Проводника пользователя.
